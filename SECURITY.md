# Security

This is a small utility library and engineering showcase. It has not undergone an independent security audit. Tests cover specific behaviours; they do not establish suitability for every deployment.

Report a suspected vulnerability privately through this repository's **Security → Advisories → Report a vulnerability** page when private reporting is enabled. Do not include credentials, user records, or exploit details in a public issue. If private reporting is unavailable, open an issue requesting a private contact without disclosing the vulnerability.

Only the latest main-branch version is maintained. There is no response-time or long-term-support commitment.

See [the integration contract](docs/integration.md) for caller responsibilities, including atomic replay protection, throttling, key management, and browser-session security.
